# Voice Note

A dead-simple speech-to-text note taker, designed to be installed on an iPhone
home screen and hosted on Vercel.

- **One button** starts/stops listening (Web Speech API — works in Safari on
  iOS and Chrome on desktop).
- **One button** emails the note to your inbox.
- The email **subject is always `time · date · two words`**, where the two-word
  summary is generated by Claude (with a first-two-words fallback if no API key
  is set).
- Off-white, full-screen, standalone-PWA friendly. No accounts, no chrome.

This is a fully standalone app — it has no dependency on any other project.

## Tech stack

Next.js 16 (App Router) · React 19 · TypeScript · [Resend](https://resend.com)
for email · [Anthropic](https://console.anthropic.com) for the two-word summary.

## Local development

```bash
npm install
cp .env.example .env.local   # fill in your keys
npm run dev                  # http://localhost:3000
```

## Environment variables

| Variable            | Required | Purpose                                                                 |
| ------------------- | -------- | ----------------------------------------------------------------------- |
| `RESEND_API_KEY`    | yes      | Sends the email via Resend.                                             |
| `NOTIFY_FROM_EMAIL` | yes      | Verified Resend sender, e.g. `Voice Note <notes@yourdomain.com>`.       |
| `NOTE_RECIPIENT`    | no       | Where notes are sent. Defaults to `devinfarren@gmail.com`.              |
| `ANTHROPIC_API_KEY` | no       | Generates the two-word subject summary. Falls back to the first two words. |

## Deploy to Vercel

1. Push this repo to GitHub (already done if you're reading this on GitHub).
2. In [Vercel](https://vercel.com/new), **Import** the repository.
3. Add the environment variables above under **Settings → Environment Variables**.
4. Deploy. Next.js is auto-detected — no build configuration needed.

## Add to your iPhone home screen

1. Open the deployed URL in **Safari** (not Chrome — only Safari can install a
   home-screen web app and grant mic access to it).
2. Tap **Share → Add to Home Screen**.
3. Launch it from the home screen. It opens full-screen, with no browser bar.
4. The first time you tap the mic, allow microphone access.

> **Note on dictation:** iOS routes the Web Speech API through Apple's speech
> service, so dictation needs a network connection. If speech isn't available,
> the app still lets you type a note and email it.
